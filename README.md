# Solex e-Vidhayalay Portal

A learning and development portal created for Solex Energies Limited.

The portal provides department-wise learning, TOPCon manufacturing training, quizzes, progress tracking, certificates and basic course administration.

## Main Features

- Solex orange and grey theme
- Responsive learning dashboard
- TOPCon manufacturing course
- Interactive lesson player
- Quiz with automatic scoring
- Course-progress tracking
- Completion certificate
- Multilingual learning support
- Admin course-management page
- Browser-based data storage
- GitHub Pages compatible
